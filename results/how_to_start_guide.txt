┌─────────────────────────────────────────────────────────────────────────────┐
│ CHOICE [1] - NORMAL GRID OPERATION                                          │
└─────────────────────────────────────────────────────────────────────────────┘

PURPOSE: Train ML models to predict grid stability (stable vs unstable)

WHAT IT DOES:
  1. Loads data from: data/dataset.csv
  2. Processes and cleans the data
  3. Trains Logistic Regression model
  4. Trains SVM model
  5. Evaluates both models
  6. Saves results

OUTPUT FILES:
  - results/lr_accuracy.txt     → LR model performance
  - results/svm_accuracy.txt    → SVM model performance
  - models/logistic_regression.pkl  → Saved LR model
  - models/svm_model.pkl        → Saved SVM model

FRESH VALUES? NO
  - Uses SAME dataset (data/dataset.csv)
  - Model weights may vary slightly due to random splits
  - Same data → Similar results each run


┌─────────────────────────────────────────────────────────────────────────────┐
│ CHOICE [2] - ATTACK DETECTION                                               │
└─────────────────────────────────────────────────────────────────────────────┘

PURPOSE: Train IDS (Intrusion Detection System) to detect cyber-attacks

WHAT IT DOES:
  1. Checks if attack data exists
  2. If NOT exists → Automatically generates new attack data
  3. Loads data from: data_attack/attack_dataset.csv
  4. Trains IDS model (RandomForest/SVM)
  5. Detects: normal vs attack (FDI, Replay, DoS, Unauthorized)

OUTPUT FILES:
  - results_attack/ids_results.txt  → IDS performance
  - results_attack/*.png            → Attack analysis plots

FRESH VALUES? DEPENDS
  - If attack_dataset.csv already exists → Uses same data (NO fresh)
  - If file missing → Generates new data (YES fresh, but with seed=42)

┌─────────────────────────────────────────────────────────────────────────────┐
│ CHOICE [4] - GENERATE ATTACK DATA  ⚠️ IMPORTANT!                            │
└─────────────────────────────────────────────────────────────────────────────┘

PURPOSE: Create NEW synthetic cyber-attack dataset

WHAT IT DOES:
  1. Generates 100 mixed samples (60% normal, 40% attack)
  2. Generates 50 pure attack samples
  3. Simulates 4 attack types:
     - FDI (False Data Injection): Fake sensor values
     - Replay Attack: Identical repeated patterns
     - DoS Attack: Random rapid fluctuations
     - Unauthorized: Suspicious access patterns
  4. OVERWRITES existing attack data files!

OUTPUT FILES:
  - data_attack/attack_dataset.csv   → Mixed normal+attack (OVERWRITTEN)
  - data_attack/pure_attack_data.csv → Pure attacks only (OVERWRITTEN)

⭐ FRESH VALUES? YES AND NO - TRICKY! ⭐

  The script uses: np.random.seed(42)
  
  This means:
  ┌───────────────────────────────────────────────────────────────────┐
  │  SAME seed(42) = SAME "random" numbers EVERY TIME                 │
  │  Running 10 times → Get IDENTICAL data 10 times                   │
  └───────────────────────────────────────────────────────────────────┘
  
  WHY? For reproducibility (research papers need same results)
  
  TO GET TRULY FRESH VALUES:
  Option A: Delete or comment out the line:
            np.random.seed(42)
            
  Option B: Change seed number:
            np.random.seed(123)  or np.random.seed(999)
            
  Option C: Use time-based seed:
            np.random.seed(int(time.time()))

  File location: python/generate_attack_data.py (Line 17)

  - Uses SAME trained models (models/*.pkl)
  - BUT random train/test split may cause SLIGHT variations
  
  The script uses: random_state=42 in train_test_split
  This means: Same data → Same split → Same graphs every time

  IF YOU WANT DIFFERENT GRAPHS:
  1. First run Choice [4] with different seed → New attack data
  2. Then run Choice [1] or [2] → Retrain models

================================================================================
               HOW TO GET TRULY FRESH/DIFFERENT VALUES
================================================================================

OPTION 1: Modify Random Seeds (Recommended)
-------------------------------------------
Files to edit:
  python/generate_attack_data.py  Line 17: np.random.seed(42)
  python/train_lr.py              Line: random_state=42
  python/train_svm.py             Line: random_state=42

Change to:
  np.random.seed(None)  → True random
  np.random.seed(123)   → Different but reproducible


OPTION 2: Use Different Dataset
-------------------------------
Replace data/dataset.csv with your own data
Keep same column structure


OPTION 3: Change Train/Test Split
---------------------------------
In training files, change:
  train_test_split(..., test_size=0.2, ...)
To:
  train_test_split(..., test_size=0.3, ...)  → 70/30 split instead of 80/20
