================================================================================
                2. DATA CLEANING (NaN & INFINITY REMOVAL)
================================================================================

CODE:
-----
    df = df[~df.isin([np.nan, np.inf, -np.inf]).any(1)]

STEP-BY-STEP EXPLANATION:
-------------------------

┌─────────────────────────────────────────────────────────────────────────────┐
│ df.isin([np.nan, np.inf, -np.inf])                                          │
│   • Checks every cell in the DataFrame                                      │
│   • Marks True if the value is:                                             │
│       ○ NaN (missing value)                                                 │
│       ○ +∞ (positive infinity)                                              │
│       ○ -∞ (negative infinity)                                              │
│                                                                             │
│ .any(1)                                                                     │
│   • Checks row-wise (axis=1)                                                │
│   • Returns True if ANY column in that row contains invalid value           │
│                                                                             │
│ ~ (tilde operator)                                                          │
│   • Negates the condition                                                   │
│   • Keeps only rows with ALL valid numerical values                         │
└─────────────────────────────────────────────────────────────────────────────┘

WHY THIS IS CRITICAL:
---------------------
    • ML algorithms CANNOT handle NaN or infinity
    • Prevents:
        ○ Training errors
        ○ Division by zero
        ○ Biased or unstable models
        ○ Gradient explosion in neural networks

RESULT: Clean, fully numerical dataset ready for ML

================================================================================
                8. LOGISTIC REGRESSION (WITH FORMULAS)
================================================================================

CODE:
-----
    from sklearn.linear_model import LogisticRegression
    lr = LogisticRegression()
    lr.fit(X_train, y_train)
    y_pred = lr.predict(X_test)

MATHEMATICAL MODEL:
-------------------

STEP 1: Linear Combination
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   z = w₀ + w₁x₁ + w₂x₂ + ... + wₙxₙ                                        │
│                                                                             │
│   z = w₀ + Σ(wᵢ × xᵢ)  for i = 1 to n                                      │
│                                                                             │
│   Or in matrix form:                                                        │
│   z = w^T × x + b                                                           │
│                                                                             │
│   where:                                                                    │
│       w = weight vector (learned parameters)                                │
│       x = feature vector (input)                                            │
│       b = bias term                                                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

STEP 2: Sigmoid (Logistic) Function
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                         1                                                   │
│   σ(z) = P(y=1|x) = ─────────────                                           │
│                       1 + e^(-z)                                            │
│                                                                             │
│   Properties:                                                               │
│       • Output range: (0, 1)                                                │
│       • σ(0) = 0.5                                                          │
│       • σ(+∞) → 1                                                           │
│       • σ(-∞) → 0                                                           │
│                                                                             │
│   Sigmoid Curve:                                                            │
│                                                                             │
│       1.0  ──────────────────────────────●●●●●●                             │
│       0.8  ─────────────────────────●●●●                                    │
│       0.5  ────────────────────●●●● ← Decision Boundary                     │
│       0.2  ───────────────●●●●                                              │
│       0.0  ●●●●●●●────────────────────────────────                          │
│           -6  -4  -2   0   2   4   6   z                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

STEP 3: Decision Rule
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   ŷ = 1   if P(y=1|x) ≥ 0.5   (Attack)                                      │
│   ŷ = 0   if P(y=1|x) < 0.5   (Normal)                                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

STEP 4: Loss Function (Binary Cross-Entropy)
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                    1   N                                                    │
│   L(w) = - ───  ×  Σ  [yᵢ × log(p̂ᵢ) + (1-yᵢ) × log(1-p̂ᵢ)]                  │
│                    N  i=1                                                   │
│                                                                             │
│   where:                                                                    │
│       N = number of samples                                                 │
│       yᵢ = true label (0 or 1)                                              │
│       p̂ᵢ = predicted probability                                            │
│                                                                             │
│   Goal: Minimize L(w) using gradient descent                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

STEP 5: Gradient Descent Update
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   w_new = w_old - α × ∂L/∂w                                                 │
│                                                                             │
│              1   N                                                          │
│   ∂L/∂w = ───  × Σ  (p̂ᵢ - yᵢ) × xᵢ                                         │
│              N  i=1                                                         │
│                                                                             │
│   where:                                                                    │
│       α = learning rate                                                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

RESULTS FOR YOUR DATA:
----------------------
    Accuracy:  77%
    Recall:    15%
    
    Confusion Matrix:
    [[679  47]
     [169  29]]

WHY LOGISTIC REGRESSION PERFORMS POORLY:
----------------------------------------
┌─────────────────────────────────────────────────────────────────────────────┐

│                                                                             │
│ Your power system data has:                                                 │

                9. SUPPORT VECTOR MACHINE (WITH FORMULAS)
================================================================================

CODE:
-----
    from sklearn.svm import SVC
    svm_clf = SVC(probability=True, max_iter=100, tol=20, random_state=42)
    svm_clf.fit(X_train, y_train)

MATHEMATICAL MODEL:
-------------------

OBJECTIVE: Find Optimal Hyperplane
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Hyperplane equation:  w · x + b = 0                                       │
│                                                                             │
│   Decision function:    f(x) = sign(w · x + b)                              │
│                                                                             │
│   Classification rule:                                                      │
│       If w · x + b ≥ 0  →  Class +1 (Attack)                                │
│       If w · x + b < 0  →  Class -1 (Normal)                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

MARGIN MAXIMIZATION:
--------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Margin = 2 / ||w||                                                        │
│                                                                             │
│   Goal: MAXIMIZE margin = MINIMIZE ||w||²                                   │
│                                                                             │
│   Optimization Problem (Primal Form):                                       │
│                                                                             │
│       Minimize:    ½ × ||w||²                                               │
│                                                                             │
│       Subject to:  yᵢ × (w · xᵢ + b) ≥ 1   for all i                        │
│                                                                             │
│   Visual Representation:                                                    │
│                                                                             │
│       Attack (●)                                                            │
│           ●  ●                                                              │
│              ●  ●                                                           │
│       ═══════════════════  ← Support Vectors (w · x + b = +1)              │
│         ↑                                                                   │
│         │ Margin                                                            │
│         ↓                                                                   │
│       ─────────────────────  ← Decision Boundary (w · x + b = 0)           │
│         ↑                                                                   │
│         │ Margin                                                            │
│         ↓                                                                   │
│       ═══════════════════  ← Support Vectors (w · x + b = -1)              │
│                   ○  ○                                                      │
│              ○  ○                                                           │
│       Normal (○)                                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

SOFT MARGIN SVM (WITH SLACK VARIABLES):
---------------------------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Real data is rarely perfectly separable.                                  │
│                                                                             │
│   Introduce slack variables ξᵢ:                                             │
│                                                                             │
│       Minimize:    ½||w||² + C × Σξᵢ                                        │
│                                                                             │
│       Subject to:  yᵢ(w · xᵢ + b) ≥ 1 - ξᵢ                                  │
│                    ξᵢ ≥ 0                                                   │
│                                                                             │
│   C = Regularization parameter:                                             │
│       • Large C → Fewer misclassifications, narrower margin                 │
│       • Small C → More misclassifications allowed, wider margin             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

KERNEL TRICK (FOR NONLINEAR DATA):
----------------------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Transform data to higher dimension using kernel function K(xᵢ, xⱼ)        │
│                                                                             │
│   Common Kernels:                                                           │
│                                                                             │
│   1. Linear:      K(xᵢ, xⱼ) = xᵢ · xⱼ                                       │
│                                                                             │
│   2. Polynomial:  K(xᵢ, xⱼ) = (γ × xᵢ · xⱼ + r)^d                           │
│                                                                             │
│   3. RBF (Gaussian): K(xᵢ, xⱼ) = exp(-γ × ||xᵢ - xⱼ||²)                     │
│                                                                             │
│   4. Sigmoid:     K(xᵢ, xⱼ) = tanh(γ × xᵢ · xⱼ + r)                         │
│                                                                             │
│   RBF Kernel (Default):                                                     │
│       • Maps to infinite-dimensional space                                  │
│       • γ controls influence radius of each sample                          │
│       • Works well for most nonlinear problems                              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

WHY SVM WORKS FOR POWER SYSTEM DATA:
------------------------------------
    • Handles high-dimensional data (many sensors)
    • RBF kernel captures nonlinear attack patterns
    • Effective even with limited samples
    • Robust to outliers (only support vectors matter)

CODE:
-----
    from sklearn.tree import DecisionTreeClassifier
    dec = DecisionTreeClassifier(criterion="entropy", max_depth=3)
    dec.fit(X_train, y_train)

MATHEMATICAL MODEL:
-------------------

ENTROPY (Information Measure):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Entropy = - Σ pᵢ × log₂(pᵢ)                                               │
│                                                                             │
│   For binary classification:                                                │
│                                                                             │
│   H(S) = -p_attack × log₂(p_attack) - p_normal × log₂(p_normal)             │
│                                                                             │
│   where:                                                                    │
│       p_attack = (# attack samples) / (total samples)                       │
│       p_normal = (# normal samples) / (total samples)                       │
│                                                                             │
│   Properties:                                                               │
│       • H = 0    → Pure node (all same class)                               │
│       • H = 1    → Maximum impurity (50-50 split)                           │
│                                                                             │
│   Example:                                                                  │
│       50% Attack, 50% Normal:                                               │
│       H = -0.5 × log₂(0.5) - 0.5 × log₂(0.5)                                │
│       H = -0.5 × (-1) - 0.5 × (-1)                                          │
│       H = 0.5 + 0.5 = 1.0 (maximum entropy)                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

INFORMATION GAIN:
-----------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Information Gain = H(parent) - Σ (|Sᵥ|/|S|) × H(Sᵥ)                       │
│                                                                             │
│   Expanded form:                                                            │
│                                                                             │
│   IG(S, A) = H(S) - Σ  (|Sᵥ|/|S|) × H(Sᵥ)                                   │
│                     v∈Values(A)                                             │
│                                                                             │
│   where:                                                                    │
│       S  = current node samples                                             │
│       A  = attribute (feature) being tested                                 │
│       Sᵥ = subset of S where attribute A has value v                        │
│                                                                             │
│   Goal: Choose split that MAXIMIZES Information Gain                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

GINI IMPURITY (Alternative to Entropy):
---------------------------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Gini(S) = 1 - Σ pᵢ²                                                       │
│                                                                             │
│   For binary classification:                                                │
│                                                                             │
│   Gini = 1 - p_attack² - p_normal²                                          │
│                                                                             │
│   Properties:                                                               │
│       • Gini = 0    → Pure node                                             │
│       • Gini = 0.5  → Maximum impurity (50-50)                              │
│                                                                             │
│   Gini is slightly faster to compute than entropy.                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

TREE BUILDING ALGORITHM (ID3/CART):
-----------------------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   1. Start with all samples at root node                                    │
│                                                                             │
│   2. For each feature:                                                      │
│      a. For each possible threshold:                                        │
│         - Split data into left and right                                    │
│         - Calculate Information Gain (or Gini reduction)                    │
│                                                                             │
│   3. Choose feature + threshold with HIGHEST Information Gain               │
│                                                                             │
│   4. Recursively repeat for child nodes                                     │
│                                                                             │
│   5. Stop when:                                                             │
│      - max_depth reached                                                    │
│      - min_samples_leaf not met                                             │
│      - Pure node achieved (Entropy = 0)                                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

EXAMPLE TREE NODE:
------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                   ┌───────────────────────┐                                 │
│                   │  Voltage ≤ 0.92?      │                                 │
│                   │  entropy = 0.85       │                                 │
│                   │  samples = 4618       │                                 │
│                   │  value = [1008, 3610] │                                 │
│                   │  class = Attack       │                                 │
│                   └───────────┬───────────┘                                 │

MATHEMATICAL MODEL:
-------------------

CONCEPT: Ensemble of Decision Trees + Bagging
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Random Forest = Bootstrap Aggregating (Bagging) + Feature Randomization   │
│                                                                             │
│   Step 1: Bootstrap Sampling                                                │
│       • Create T different training sets by sampling WITH replacement       │
│       • Each bootstrap sample ≈ 63.2% unique samples                        │
│                                                                             │
│   Step 2: Train Individual Trees                                            │
│       • Each tree trained on different bootstrap sample                     │
│       • At each split, only √m features considered (m = total features)     │
│                                                                             │
│   Step 3: Aggregate Predictions                                             │
│       • Each tree votes                                                     │
│       • Final prediction = MAJORITY VOTE                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

ENSEMBLE PREDICTION:
--------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   For classification (majority voting):                                     │
│                                                                             │
│                    T                                                        │
│   ŷ = mode { hₜ(x) }                                                        │
│                   t=1                                                       │
│                                                                             │
│   where:                                                                    │
│       T = number of trees (n_estimators)                                    │
│       hₜ(x) = prediction of tree t                                          │
│                                                                             │
│   For probability:                                                          │
│                                                                             │
│                1   T                                                        │
│   P(y=1|x) = ───  Σ  pₜ(y=1|x)                                              │
│                T  t=1                                                       │
│                                                                             │
│   (Average of all tree probabilities)                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

VARIANCE REDUCTION:
-------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Single tree variance: Var(h)                                              │
│                                                                             │
│   Ensemble variance:                                                        │
│                                                                             │
│            Var(h)                                                           │
│   Var = ────────── + ρ × (1 - 1/T) × Var(h)                                 │
│              T                                                              │
│                                                                             │
│   where:                                                                    │
│       T = number of trees                                                   │

│                                                                             │
│   Key insight:                                                              │
│       • Random feature selection → Lower tree correlation (ρ)               │
│       • Lower ρ → Lower variance → Better generalization                    │
│                                                                             │

                13. XGBOOST CLASSIFIER (WITH FORMULAS)
================================================================================

CODE:
-----
    from xgboost import XGBClassifier
    xgb = XGBClassifier()
    xgb.fit(X_train, y_train)

MATHEMATICAL MODEL:
-------------------

CONCEPT: Gradient Boosting with Regularization
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Boosting = Sequential ensemble where each tree CORRECTS previous errors   │
│                                                                             │
│   Model at iteration t:                                                     │
│                                                                             │
│   ŷᵢ^(t) = ŷᵢ^(t-1) + η × fₜ(xᵢ)                                            │
│                                                                             │
│   where:                                                                    │
│       ŷᵢ^(t-1) = prediction from previous iteration                         │
│       fₜ(xᵢ)   = new tree that fits the RESIDUAL                            │
│       η        = learning rate (shrinkage)                                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

OBJECTIVE FUNCTION:
-------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Obj = Σ L(yᵢ, ŷᵢ) + Σ Ω(fₖ)                                               │
│          i            k                                                     │
│                                                                             │
│   where:                                                                    │
│       L = Loss function (e.g., Log Loss for classification)                 │
│       Ω = Regularization term                                               │
│                                                                             │
│   Regularization:                                                           │
│                                                                             │
│   Ω(f) = γT + ½λΣwⱼ²                                                        │
│                                                                             │
│   where:                                                                    │
│       T  = number of leaves in tree                                         │
│       wⱼ = weight of leaf j                                                 │
│       γ  = leaf number penalty                                              │
│       λ  = L2 regularization on weights                                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

GRADIENT AND HESSIAN:
---------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   XGBoost uses second-order Taylor expansion:                               │
│                                                                             │
│   gᵢ = ∂L/∂ŷᵢ^(t-1)         (First derivative - gradient)                   │
│   hᵢ = ∂²L/∂(ŷᵢ^(t-1))²    (Second derivative - hessian)                   │
│                                                                             │
│   Approximate objective:                                                    │
│                                                                             │
│   Obj ≈ Σ [gᵢfₜ(xᵢ) + ½hᵢfₜ(xᵢ)²] + Ω(fₜ)                                   │
│          i                                                                  │
│                                                                             │
│   Optimal leaf weight:                                                      │
│                                                                             │
│            Σ gᵢ                                                             │
│   wⱼ* = - ─────────                                                         │
│           Σ hᵢ + λ                                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

SPLIT GAIN FORMULA:
-------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│             1    (ΣgL)²       (ΣgR)²       (ΣgL + ΣgR)²                     │
│   Gain = ───  [ ───────── + ───────── - ───────────────── ] - γ             │
│             2    ΣhL + λ     ΣhR + λ     ΣhL + ΣhR + λ                      │
│                                                                             │
│   where:                                                                    │
│       L, R = left and right child nodes                                     │
│       gL, gR = sum of gradients in each child                               │
│       hL, hR = sum of hessians in each child                                │
│                                                                             │
│   If Gain > 0 → Split is beneficial                                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

MATHEMATICAL MODEL:
-------------------

HARD VOTING (Majority Voting):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                    K                                                        │
│   ŷ = mode { hₖ(x) }                                                        │
│                   k=1                                                       │
│                                                                             │
│   Each classifier votes, majority wins.                                     │
│                                                                             │
│   Example with 4 classifiers:                                               │
│       RF: Attack (1)                                                        │
│       ETC: Attack (1)                                                       │
│       SVM: Normal (0)                                                       │
│       MLP: Attack (1)                                                       │
│                                                                             │
│       Final: Attack (3 votes to 1)                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

SOFT VOTING (Probability Averaging):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                1   K                                                        │
│   P(y=c|x) = ───  Σ  pₖ(y=c|x)                                              │
│                K  k=1                                                       │
│                                                                             │
│   ŷ = argmax P(y=c|x)                                                       │
│          c                                                                  │
│                                                                             │
│   Average probabilities, then pick highest.                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

WHY VOTING WORKS:
-----------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Condorcet Jury Theorem (simplified):                                      │
│                                                                             │
│   If each classifier is better than random (accuracy > 50%)                 │
│   AND classifiers make INDEPENDENT errors                                   │
│   THEN ensemble accuracy approaches 100% as K increases                     │
│                                                                             │
│   Mathematical bound:                                                       │
│                                                                             │
│   P(majority correct) = Σ C(K,k) × pᵏ × (1-p)^(K-k)                         │
│                        k>K/2                                                │
│                                                                             │
│   For K=5 classifiers with p=0.7:                                           │
│   P(majority) ≈ 0.84 > 0.70                                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

        • Random Forest (tree ensemble)

                16. EVALUATION METRICS (ALL FORMULAS)
================================================================================

CONFUSION MATRIX STRUCTURE:
---------------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                           PREDICTED                                         │
│                     Negative        Positive                                │
│                  ┌──────────────┬──────────────┐                            │
│       Negative   │      TN      │      FP      │                            │
│       ACTUAL     ├──────────────┼──────────────┤                            │
│       Positive   │      FN      │      TP      │                            │
│                  └──────────────┴──────────────┘                            │
│                                                                             │
│   TN (True Negative)  = Correctly predicted Normal                          │
│   TP (True Positive)  = Correctly predicted Attack                          │
│   FP (False Positive) = Type I Error (False alarm)                          │
│   FN (False Negative) = Type II Error (Missed attack) ← DANGEROUS!          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

ALL METRIC FORMULAS:
--------------------

1. ACCURACY:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                      TP + TN                                                │
│   Accuracy = ─────────────────────────                                      │
│               TP + TN + FP + FN                                             │
│                                                                             │
│   Interpretation: Overall correctness                                       │
│   Range: 0 to 1                                                             │
│                                                                             │
│   ⚠ WARNING: Misleading with imbalanced data!                               │
│        Example: 95% Normal → Always predict Normal = 95% accuracy           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

2. PRECISION:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                        TP                                                   │
│   Precision = ─────────────────                                             │
│                  TP + FP                                                    │
│                                                                             │
│   Question: "Of all ATTACK predictions, how many were correct?"             │
│                                                                             │
│   High Precision = Few false alarms                                         │
│   Use when: False alarms are costly (unnecessary shutdowns)                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

3. RECALL (SENSITIVITY / TRUE POSITIVE RATE):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                     TP                                                      │
│   Recall = ─────────────────                                                │
│               TP + FN                                                       │
│                                                                             │
│   Question: "Of all ACTUAL attacks, how many were detected?"                │
│                                                                             │
│   High Recall = Few missed attacks                                          │
│   Use when: Missing attacks is dangerous (power system protection!)         │
│                                                                             │
│   ⚠ CRITICAL for your project: Prioritize RECALL!                          │
│   Missing a cyber-attack can cause grid instability!                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

4. SPECIFICITY (TRUE NEGATIVE RATE):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                        TN                                                   │
│   Specificity = ─────────────────                                           │
│                    TN + FP                                                  │
│                                                                             │
│   Question: "Of all NORMAL conditions, how many correctly identified?"      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

5. F1 SCORE (HARMONIC MEAN):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                2 × Precision × Recall                                       │
│   F1 Score = ───────────────────────────                                    │
│                Precision + Recall                                           │
│                                                                             │
│   Alternative formula:                                                      │
│                                                                             │
│                       2 × TP                                                │
│   F1 Score = ─────────────────────────                                      │
│               2×TP + FP + FN                                                │
│                                                                             │
│   Why Harmonic Mean (not arithmetic)?                                       │
│       • Penalizes extreme differences                                       │
│       • F1 = 0.5 if Precision=1.0 and Recall=0.33                           │
│       • Better single metric for imbalanced data                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

6. F-BETA SCORE (WEIGHTED):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                (1 + β²) × Precision × Recall                                │
│   F_β = ─────────────────────────────────────                               │
│              β² × Precision + Recall                                        │
│                                                                             │
│   β > 1: Emphasizes Recall (safety-critical, use β=2)                       │
│   β < 1: Emphasizes Precision (cost-sensitive, use β=0.5)                   │
│   β = 1: Balanced (standard F1)                                             │
│                                                                             │
│   For power system IDS: Use F2 (recall matters more!)                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

CODE:
-----
    from sklearn.model_selection import StratifiedKFold, cross_val_score
    skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
    scores = cross_val_score(model, X, y, cv=skf, scoring='accuracy')

STRATIFIED K-FOLD EXPLANATION:
------------------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   K-Fold Cross-Validation:                                                  │
│       • Split data into K equal parts (folds)                               │
│       • Train on K-1 folds, test on 1 fold                                  │
│       • Repeat K times, each fold used as test once                         │
│                                                                             │
│   For K=5:                                                                  │
│                                                                             │
│   Fold 1: [ TEST | Train | Train | Train | Train ]                          │
│   Fold 2: [ Train | TEST | Train | Train | Train ]                          │
│   Fold 3: [ Train | Train | TEST | Train | Train ]                          │
│   Fold 4: [ Train | Train | Train | TEST | Train ]                          │
│   Fold 5: [ Train | Train | Train | Train | TEST ]                          │
│                                                                             │
│   STRATIFIED means:                                                         │
│       Each fold maintains same class ratio as original data                 │
│       Essential for imbalanced datasets!                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

AGGREGATION FORMULAS:
---------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Mean CV Score:                                                            │
│                                                                             │
│                   1   K                                                     │
│   Mean Score = ───  × Σ  Score_k                                            │
│                   K  k=1                                                    │
│                                                                             │
│   Standard Deviation:                                                       │
│                     ______________________________                          │
│                    /  1   K                                                 │
│   Std Score = √  ───  × Σ  (Score_k - Mean)²                                │
│                    K  k=1                                                   │
│                                                                             │
│   Example output:                                                           │
│       CV Scores: [0.95, 0.97, 0.96, 0.94, 0.97]                             │
│       Mean: 0.958                                                           │
│       Std: 0.012                                                            │
│                                                                             │
│   Result: 95.8% ± 1.2% accuracy                                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

LOG LOSS (FOR PROBABILITY EVALUATION):
--------------------------------------
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                    1   N                                                    │
│   Log Loss = - ───  × Σ  [yᵢ × log(p̂ᵢ) + (1-yᵢ) × log(1-p̂ᵢ)]                │
│                    N  i=1                                                   │
│                                                                             │
│   Properties:                                                               │
│       • Heavily penalizes confident wrong predictions                       │
│       • Log Loss = 0 for perfect predictions                                │
│       • Lower is better                                                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
