# QUICK REFERENCE SHEET - EV SmartGrid ML Project

## Project Essence
- **Goal**: Detect cyber-attacks and predict grid stability in smart grids with EV charging
- **ML Approach**: Logistic Regression (LR) & Support Vector Machine (SVM) for real-time classification
- **Performance**: ~98% accuracy for both grid stability and attack detection
- **Key Advantage**: Privacy-preserving, federated learning capable

## Data Overview
- **Training Data**: 5000 samples of hourly grid measurements (normal operation)
- **Attack Data**: Simulated cyber-attacks (FDI, Replay, DoS, Unauthorized)
- **Features**: 11 raw + 15+ engineered features
- **Classes**: Binary (stable/unstable, normal/attack)

## Dataset Columns
```
timestamp, hour, voltage, current, active_power, reactive_power,
frequency, ev_demand, total_load, temperature, grid_stability
```

## Key Formulas

### Power Features
- Apparent Power: S = √(P² + Q²)
- Power Factor: PF = P/S
- Voltage Deviation: ΔV = |V - 1.0|
- Voltage Squared: V²

### Time Features
- Hour_sin = sin(2π × hour/24)
- Hour_cos = cos(2π × hour/24)
- Is_peak_hour = 1 if 17≤hour≤21 else 0

### Preprocessing
- Standardization: z = (x - μ)/σ
- Label Encoding: stable→0, unstable→1

### ML Models
- **LR**: h(x) = 1/(1 + e^(-z))
- **SVM RBF**: K(x,y) = exp(-γ||x-y||²)

## Attack Types Detected

1. **False Data Injection (FDI)**
   - Abnormal voltage/frequency out of range
   - Impossible EV demand values

2. **Replay Attack**
   - Exact value repetition
   - Same measurements repeating identically

3. **DoS Attack**
   - Rapid fluctuations in all parameters
   - Designed to overwhelm systems

4. **Unauthorized Access**
   - Suspicious charging at odd hours
   - Unusual power patterns (2-4 AM)

## Evaluation Metrics Explained

```
Confusion Matrix:
        Predicted
       Pos  Neg
Actual
Pos     TP   FN
Neg     FP   TN

Accuracy = (TP+TN)/(TP+TN+FP+FN)
Precision = TP/(TP+FP)          → False alarms
Recall = TP/(TP+FN)             → Missed attacks
F1 = 2×(P×R)/(P+R)              → Balanced score
```

## Hyperparameters Used

### Logistic Regression
- C = 1.0
- penalty = 'l2'
- solver = 'lbfgs'
- max_iter = 1000

### SVM (RBF)
- C = 1.0
- kernel = 'rbf'
- gamma = 'scale'
- probability = True

### Train-Test Split
- test_size = 0.2 (80/20 split)
- random_state = 42 (reproducible)
- stratify = True (maintain class proportion)

### Cross-Validation
- cv = 5 folds
- scoring = 'accuracy'

## Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Low accuracy | Check for data leakage in scaling |
| Overfitting | Increase regularization (lower C) |
| Slow training | Use faster solver or fewer features |
| Imbalanced results | Use class_weight='balanced' |
| Memory error | Reduce dataset size or batch processing |
